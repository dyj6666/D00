## 一、⭐ XPT2046 触摸屏驱动（bsp_touch.c）—— 位操作 SPI

### 1.1 概况
- **位操作 SPI（非硬件外设）**：CLK=PB0 / PEN=PB1 / MISO=PB2 / CS=PC13 / MOSI=PF11
- **1MHz 慢速 SPI**（:28-30）："弱接触（高源阻抗）时采样保持电容需要更长获取时间，慢速 SCLK 显著改善轻触读数稳定性"——**触摸稳定性优先于速度**

### 1.2 读数路径（多层滤波）
```
BSP_Touch_ReadRaw（快速路径）：
  → 3 次中值 X 读（tp_read_xoy3）——快速探测：超范围（无触摸）立即返回省开销
  → 有效 → 全量：X/Y 各 5 次去极值均值（tp_read_xoy：排序后去掉两端各 1）
  → 触点范围判定（TOUCH_RAW_MIN=5 / MAX=4090——放宽阈值：极轻触也识别）
  → 不做双次校验（注释：轻触抖动不误拒，噪声由上层平滑吸收）
BSP_Touch_ReadRawForce（校准/诊断）：
  → 双次校验（两次读数差 <80 才接受）——校准要确定性
```

### 1.3 命令与转换
- `CMD_X_POS=0xD0 / CMD_Y_POS=0x90`（S=1, 12bit, PD=00）
- 读 16 位高 12 位有效（`num >>= 4`）
- 转换等待 6µs（XPT2046 最大转换时间）；清 BUSY 时钟

### 1.4 坐标转换（Convert :253-266）
```c
x = (rx - xc) / xfac + w/2     // 出厂默认 xfac=18 xc=2048（近似值，建议 touch cal 精校准）
y = (ry - yc) / yfac + h/2     // 钳位到 [0, w-1] / [0, h-1]
```
校准参数 EEPROM 持久化（touch_svc 笔记 14 呼应：四角校准 → UsrStore）。

### 1.5 互斥
- `s_io_lock` 串行化 SPI 访问（采样/校准互斥）——位操作时序不能被并发打断

## 二、GPIO 抽象（bsp_gpio.c，27 行）

- `BSP_LED_Set/Toggle(index)`：LED0/LED1（pinout.h 定义，`LED_ON_STATE` 电平抽象）
- `BSP_KeyPressed()`：KEY0 状态（`KEY0_PRESSED_STATE` 抽象）——key_app 消抖依赖

## 三、设计亮点

1. **1MHz 慢速 SPI**：轻触稳定性优先（采样保持电容获取时间）
2. **分层滤波**：3 次中值快速探测 → 5 次去极值全量——速度/稳定性兼顾
3. **放宽触点阈值**：极轻触识别（边缘弱接触）
4. **双次校验仅校准用**：诊断确定性 vs 运行抗抖动分离
5. **出厂默认校准**：开箱即用（近似值），精校准可选
6. **位操作 SPI 无外设依赖**：引脚任意（跨 PCB 布局灵活性）
