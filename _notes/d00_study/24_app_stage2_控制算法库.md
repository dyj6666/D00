## 一、⭐ PID 全家族（14 变式，pid.c）

| # | 变式 | 核心思想 |
| --- | --- | --- |
| 01 | 位置式 PID | 全特性版：积分分离 + 微分低通（`df_alpha`）+ 双重限幅（输出/积分） |
| 02 | 增量式 | `Δu = Kp(e1-e2) + Ki·e1 + Kd(e1-2e2+e3)/dt`——输出变化量，无积分饱和 |
| 03 | 串级 | 外环输出 = 内环目标（如期望角速度）→ 内环误差 = 外环输出 - 内环测量 |
| 04 | 前馈 | `u = PID + ff_gain × ff_input`——前馈补偿已知扰动 |
| 05 | 积分分离 | 大偏差冻结积分（防超调） |
| 06 | **抗饱和（Back-Calculation）** | 饱和差 `(u - u_unsat)` 以 `kb` 反馈回积分器——windup 根治 |
| 07 | 微分先行 | **对测量微分**（目标阶跃不产生微分冲击） |
| 08 | 增益调度 | 按调度变量分段 + **线性插值相邻段**（平滑过渡） |
| 09 | **模糊 PID** | 三角隶属度 + 25 格经验规则表（ΔKp/ΔKi/ΔKd）+ **重心法去模糊** |
| 10 | 史密斯预估器 | 模型+延迟队列补偿——控制器面对"无延迟对象" |
| 11 | Bang-Bang+PID 混合 | 大误差继电器、小误差 PID |
| 12 | **继电反馈自整定** | 极限环法：继电器激励 → 测 Tu/a → **Ziegler-Nichols 公式出 Kp/Ki/Kd** |
| 13 | 单神经元自适应 | 输入 x1=e/x2=Δe/x3=Δ²e，**Hebb 学习律**在线调权 |
| 14 | 死区+限速 | 死区防机械抖动 + 输出变化率限制 |

### 数值纪律（头注释）
- 积分显式欧拉累加，输出前限幅
- 微分一阶后向差分 + 可选低通（抑制噪声放大）
- **所有除法带零值守卫**（`dt <= 0` 直接返回 0）
- Init 时默认宽限幅（`out_min/max = ±1e6`，否则 clamp 恒 0 的坑）

### 精妙细节
1. **微分先行负号**（:65）：`d(SP-MV)/dt = -dMV/dt`——对测量微分要取负
2. **抗饱和 Back-Calculation**（:228）：积分器不仅累加 `Ki·err·dt`，还累加 `kb×(u-u_unsat)×dt`——饱和时积分器被"拉回"
3. **史密斯预估器**（:415-436）：`err_smith = (SP - 实际) - (延迟模型输出 - 无延迟模型输出)`——环形延迟队列读最旧
4. **自整定**（:477-521）：继电器滞环 `±h` → 过零检测半周期 → Tu 滑动平均 → `Ku = 4h/(π·a)` → Z-N 公式（Kp=0.6Ku, Ki=Kp/(0.5Tu), Kd=Kp·0.125Tu）
5. **模糊 PID 规则表**（:323-348）：误差大且误差率平稳 → 收紧比例防过冲；误差率大 → 减小增益防振荡——工程经验编码成表

## 三、设计亮点

1. **算法库纯粹性**：无 OS/HAL 依赖——主机可单测（test_ctrl.c 743 行验证）
2. **零除法风险**：所有除法带守卫
3. **公式来源明确**：RBJ 音频 EQ 公式 / 巴特沃斯极点对 / Ziegler-Nichols / Savitzky-Golay 核——可追溯
4. **工程经验编码**：模糊规则表 / 微分低通 / 积分分离——"防超调防振荡"的实操组合
5. **FPU 直接加速**：float 单精度，M4F 硬件浮点
