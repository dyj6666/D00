## 二、data_agent.c（86 行）—— HOSTLINK 周期上报

```
DataAgent 任务（10ms 周期）：
  WDOG 注册 + 无条件心跳（与是否有订阅无关）★
  → g_system_tick 快照（上位机读）
  → VAR_GetSubscribedList → 逐变量读 → 组 CMD_DATA 帧
      · 帧格式：id(2) + var_len(1) + reserved(1) + value
      · 严格防溢出：`idx + 4 + var_len > sizeof(buf)-2` 即 break
  → DataLink_SendPacket（自动 CRC）
```

**关键点**：
1. **心跳必须无条件上报**（:35）——任务级看门狗防误判（即使无订阅也要踢）
2. **独立任务而非定时器**：避免占用定时器服务任务栈（头注释）
3. **防溢出纪律**：组包每项检查边界（512B 缓冲，帧最大 256B 会截断——实际 DataLink 层有帧长上限，超长自动 break）
4. **栈 1024**：峰值 ~664B（HW 218 词）
5. **sys_tick 变量注册**：上位机可读系统运行节拍

## 三、设计亮点

1. **估计算法全家桶**：从标量 KF 到粒子滤波——教学+工程双用途（GIMBAL 实验对比）
2. **数值方法多样**：EKF 数值雅可比 / UKF Sigma 点 / 平方根 / IMM——覆盖非线性/多模型/数值稳定性场景
3. **数据代理独立任务**：周期上报不阻塞业务
4. **无条件心跳**：看门狗语义正确性（无订阅也踢）
