## 一、16MB 分区布局（ext_store.c:4-15, 41-52）

| 分区 | 基址 | 大小 | 标志 | 用途 |
| --- | --- | --- | --- | --- |
| ota_dl | 0x000000 | 2MB | 可写 | OTA 下载槽（方案B 由 BOOT 读） |
| img_lib | 0x200000 | 2MB | 可写+**BOOT_CRIT** | 固件镜像/回滚源 |
| fs | 0x400000 | 8MB | 可写 | LittleFS 预留 |
| user | 0xC00000 | 3MB | 可写 | 用户数据 |
| meta | 0xF00000 | 1MB | 可写+**BOOT_CRIT** | 分区表镜像×2 / 坏区表×2 / 会话预留 |

**META 内部布局**（:34-38）：PART_A/B（分区表双份）+ BAD_A/B（坏区表双份）。
**BOOT_CRIT 标志**：BOOT 侧只认 ota_dl/img_lib 的物理地址（esp_flash.h），此处标志用于 APP 侧保护。

## 二、⭐ 坏区管理（4KB 扇区位图，双份 + CRC）

```
坏区表：magic 'BADM'(4B) + crc32(4B) + bitmap[128](512B) = 520B → 存 4KB 扇区
4096bit 位图 = 16MB/4KB 全片扇区数；bit=1 表示该扇区坏
```

- **读**（bad_map_read :139-160）：先主(A)后副(B)，magic+CRC 校验，双份无效按"全新全好"
- **写**（bad_map_write :162-180）：CRC 先清零再整体计算（读写同规则）；主/副各擦各写
- **标记**（ExtStore_MarkBad :199-225）：擦除失败自动标记；后续操作自动规避
- **擦除策略**（ext_erase_range_locked :304-346）：
  ```
  优先 64KB 块擦：块内无坏区整块擦（快）；有坏区 → 逐 4KB 扇区擦并跳过坏区
  擦失败 → MarkBad → 跳过继续（绝不中断整体擦除）
  ```
- **写前检查**（ExtStore_Write :376-382）：check-then-act 原子（持锁），坏区不写

## 三、⭐ 掉电安全双份写（WriteSafe/ReadSafe）

**帧结构**（:100-105）：`magic 'EXFS' + len(2B) + ver(2B) + data[] + CRC32(4B)`，CRC 覆盖 magic..data（不含自身）。

**WriteSafe**（:389-462）：
```
校验（stride 4KB 整数倍 / 长度 ≤512 / 分区可写）→ 持递归锁
  → 构造帧（静态缓冲 s_safe_frame）
  → 擦主副两槽（坏区检查+标记）
  → 先写副(B)，再写主(A=提交点)   ★ 掉电时主未写完则读副
  → 读回校验主帧（独立缓冲 s_safe_check）
```

**ReadSafe**（:464-510）：主有效取主，否则取副；双份无效 → ERR_CRC。

**设计要点**：
1. **主为提交点**：写副 → 写主，读主优先——掉电任意时刻至少一份完整
2. **磨损均衡**：双份固定交替写，写寿命天然均衡（无动态搬移）
3. **递归互斥**（:69-79）：WriteSafe 失败时内部 MarkBad 可重入（嵌套调用不死锁）；共享静态帧缓冲防并发踩踏
4. **stride 必须 4KB 整数倍**：双份各占整扇区，擦/写地址对齐

## 四、与 BOOT esp_flash 的呼应

| 维度 | BOOT esp_flash（裸驱动） | APP ext_store（服务层） |
| --- | --- | --- |
| 层位 | 传输/存储底层 | 存储服务层 |
| 分区 | 硬编码常量（esp_flash.h） | 分区表结构体（可枚举） |
| 坏区 | 无 | 位图 + 自动规避 |
| 掉电安全 | 无（BOOT 靠流程校验） | WriteSafe 双份 |
| 互斥 | 无 OS 不需要 | 递归互斥锁 |
| CRC | 无 | 帧级 CRC32 |

**BOOT 只读 ota_dl/img_lib 物理地址**，APP 通过本层写同一颗 Flash——两者不共享驱动（BOOT 精简独立实现），靠物理地址约定对齐。

## 五、设计亮点

1. **坏区表 = 0 成本冗余**：520B 位图覆盖全片，擦失败自动标记自动规避——Flash 寿命末期仍可用
2. **64KB 块擦优先**：无坏区整块快擦，有坏区自动降级逐扇区——性能与可靠性的自适应
3. **提交点语义**：主副交替 + 主优先读——掉电安全不依赖任何日志/事务
4. **check-then-act 原子**：写前坏区检查持锁，杜绝并发写坏区
5. **静态帧缓冲 + 递归锁**：无堆分配，锁内嵌套安全
