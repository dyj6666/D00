## 一、⭐ 音频服务（audio_svc.c）—— ISR 内纯查表合成

### 1.1 播放机制（头注释 :4-10）
- 48kHz / 16bit / 双声道（L=R），I2S 标准 Philips
- **双缓冲**（各 480 样本 = 10ms），DMA 循环 + TC 中断（100Hz）填充"DMA 未读"的缓冲
- **正弦合成**：256 项查表 + 相位累加（`步进 = freq × 2^32 / 48000`），**ISR 内纯查表填充（无锁、无浮点）**
- **缓冲分配自外部 SRAM 池**（ExtMem_Alloc），主 RAM 零占用

### 1.2 三种波形源
| 源 | 实现 |
| --- | --- |
| TONE | 相位累加查表（audio_fill :123-135）：`v = tbl[(ph >> 24) & 0xFF]`，相位 32bit 定点（高 8 位查表） |
| WAV | **标准 PCM WAV 解析**（wav_parse :75-120）：RIFF/WAVE 魔数 + fmt 块校验（仅 PCM16、1/2 声道）+ **data 块定位（支持 fmt 后附加块）**；单声道复制到 L/R、双声道直通、尾部静音补尾 |
| 开机旋律 | `Audio_PlayWav(g_wav_startup, ...)`——**WAV 数据以 C 数组编进固件**（wav_data.c 19k 行） |

### 1.3 关键设计
1. **ISR 无锁无浮点**：audio_tx_cb（:163-174）在 DMA TC 中断里直接查表填充——ISR 内绝不做 malloc/浮点/锁
2. **音量 0~33**：`Audio_SetVolume` 钳制 + ES8388 喇叭音量
3. **播放替换语义**（:264-267）：播放中调用 → `s_stop_req=1` + `xQueueReset` 清旧请求——新请求立即生效
4. **任务栈 1KB**：audio_task 无大局部变量（wav_parse 仅 8B 结构）
5. **模块优先级 75 的呼应**：启动堆峰值时 OTA/HTTP alloc 优先（module.c 注释）

## 二、⭐ IMU 姿态服务（imu_svc.c）—— 工业级数据管线

### 2.1 数据管线（头注释 :18-34）
```
BSP(MPU6050) → 静态零偏校准 → 轴映射(X/Y对调)
  → 2D 卡尔曼（角度+陀螺零偏双状态，加速度计直接测量）——六轴 IMU 倾角的最优线性估计器
  → 偏航积分 + 静止漂移抑制 → 欧拉→四元数 → 共享状态
  （并行对比通道：互补滤波，供 GIMBAL 实验室同屏对比）
```

### 2.2 卡尔曼为什么是"最大化应用"（注释明示的 3 条）
1. **双状态（角度+零偏）**：陀螺零偏运行中在线估计，优于仅启动校准的静态补偿
2. **加速度计直接作测量**（atan2 重力方向）：融合即最优，而非对已融合输出做后置平滑
3. **陀螺做预测**（角速度积分 + 协方差传播）：快速运动保持响应，静止时收敛到加速度计参考

### 2.3 运动自适应测量噪声（:213-220）
```c
float r_meas = KF_R_BASE + KF_R_MOTION * gyro_mag;   // 静止低 R（信加速度计）
                                                    // 运动高 R（跟陀螺预测）
```
→ **实时性与平稳性兼得**——静止收敛稳定、运动无滞后。

### 2.4 偏航漂移抑制（:188-205）
静止检测（|a|-1<0.06 且 |g|<0.25）→ 累计 100 样本求平均 gz 零漂 → 在线扣除。**偏航无磁力计修正，纯积分**——静止时漂移被持续估计并消除。

### 2.5 健壮性与工程细节
- **200Hz 精确节拍**：`vTaskDelayUntil` 消除累积抖动（:163-164, 280）
- **dt 钳制**（:167-170）：`dt ∈ [0.001, 0.05]`——防调度饥饿时积分爆炸
- **初始化失败自愈**（:136-141）：驱动带总线释放，2s 重试——覆盖上电时序未稳/I2C 从机钳位瞬态
- **栈 2048 的血泪注释**（:36-38）：GCC+newlib 浮点打印（%+.3f）栈深明显大于 Keil（HW 664B）；1024B 在校准后打印时溢出（实测 Stack Overflow 复位循环）
- **定点格式化**（ImuSvc_FormatFixed :110-125）：不依赖 %f，省 Flash
- **欧拉→四元数**（:248-263）：供 LVGL 立方体显示；镜像约定（q1/q2 取反）注释"用户确认"

### 2.6 输出
共享状态 `imu_svc_state_t`：欧拉角（deg）+ 四元数 + 原始轴数据 + 温度 + 对比通道（acc/comp）+ 故障计数 + 采样计数。

## 三、设计亮点

1. **ISR 合成纪律**：音频填充 ISR 内无锁无浮点纯查表——中断延迟可控
2. **卡尔曼在线估计**：零偏在线学习 + 运动自适应 R——"最优"不是口号
3. **vTaskDelayUntil 精确节拍**：200Hz 无累积抖动
4. **dt 钳制防爆炸**：调度饥饿不产生 NaN
5. **初始化自愈重试**：瞬态故障不锁死任务
6. **双通道对比**：原始/互补/KF 同屏对比（教学+调试价值）
