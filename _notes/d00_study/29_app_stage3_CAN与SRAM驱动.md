## 一、⭐ CAN1 驱动（bsp_can.c）—— 性能拉满：1Mbps / 双 FIFO / 3 邮箱

### 1.1 线程模型（头注释 :6-9）
```
RX：FIFO0/FIFO1 中断 → 静默入队（ISR 零业务）→ canRx 任务分发回调
TX：调用方入 TX 队列 → canTx 任务批量填满 3 邮箱（线速发送）
ERR：SCE 中断 → HAL_CAN_ErrorCallback 累计等级/溢出计数（ABOM 自愈）
```

### 1.2 位定时（1Mbps，:56-62）
- APB1=42MHz，Prescaler=2 → **21MHz TQ**；1+15+5=21TQ → 1Mbps
- **采样点 76.2%**（1Mbps 推荐区间）
- ABOM 自动 bus-off 恢复 / NART=0 竞争自动重发 / **TXFP 按请求顺序出帧**

### 1.3 滤波：全收 + 软件分流（:74-89）
双 bank 掩码全 0（全收）→ FIFO0/FIFO1 并行 → **软件按 ID 分流**（Shell 0x100 / OTA 0x200/0x201 / 回显 0x210）——共享总线的多消费者架构。

### 1.4 ⭐ 三任务设计
| 任务 | 优先级 | 职责 |
| --- | --- | --- |
| canRx | Low1（**高于 canTx**） | 出队 → 分发回调（任务上下文，可安全调命令框架） |
| canTx | Low | 出队 → **批量填满 3 邮箱**（1Mbps 线速，永不丢弃） |

- **RX 高于 TX**（:252-254）：突发收发时 RX 任务先排空队列，防 ISR 丢帧；TX 以总线速率自然节流
- **ISR 零业务**：FIFO 中断只排空入队（rx_drop 计数），分发在任务上下文
- **TX 批量填邮箱**（:137-155）：首帧 + 趁邮箱空闲连续填充队列剩余帧——吞吐拉满

### 1.5 错误管理
- SCE 中断累计：EWG/EPV/BOF/RX_OVR 分级计数（:200-216）
- **ABOM 自愈**：bus-off 自动恢复；`BSP_CAN_IsActive` 读 ESR.BOFF 判可用
- TEC/REC 错误计数器可读（诊断）
- **总线负载估算**（:24, 309-318）：`CAN_FRAME_BITS = 47 + 10×DLC`，500ms 窗口差分 → ‰

## 二、外部 SRAM 驱动（bsp_sram.c）—— 上电自检 + 吞吐基准

### 2.1 自检三件套（~10ms 级，:33-106）
| 测试 | 方法 | 抓什么 |
| --- | --- | --- |
| 数据线 | 16 位走位（0x0001 逐位左移） | 相邻数据线短路/断路 |
| 地址线 | 低位 2B 步进（32 点）+ 高位 0x800 步进（512 点）写唯一值回读 | 地址译码错误（焊接虚焊/短路） |
| 模式 | 0x5555/0xAAAA/全0/全1 + **LCG 伪随机 4KB**（确定性种子可复现） | 单元粘连 |

**自检时机**（:11-12）：模块 priority=2，**早于 LA_Sample(30)/GuiApp(55)**，全区可写；随后 ExtMem_Init 清零池，无残留污染。

### 2.2 吞吐基准（DWT @168MHz）
32/16 位读写 + 32 位对齐拷贝（256KB 样本）→ MB/s 入启动日志与 GUI SRAM 页。
**拷贝越界血泪**（:158-161）：旧实现 dst=src+256KB 会越界 2KB 到空地址空间——现用池首 → 池首+128KB（总占用 256KB < 池 376KB）。

### 2.3 BSP_SRAM_Memcpy32（:170-203）
- 非对齐兜底 memcpy；对齐走 **4× 展开主循环**——FSMC 16 位总线下 word 访问 = 背靠背 16 位周期，循环开销摊薄到 4 次访问
- 尾部字节处理

### 2.4 FSMC 验证（:215-227）
BCR3/BTR3 时序回读（ADDSET/DATAST）+ BANK3 使能验证——FSMC 配置可观测。

## 三、设计亮点

1. **CAN 全收+软件分流**：共享总线多消费者（Shell/OTA/回显）统一架构
2. **ISR 零业务 + 双任务**：RX 优先防丢帧，TX 批量线速
3. **ABOM 自愈 + 分级计数**：错误可观测可恢复
4. **SRAM 自检分层**：数据线→地址线→模式——故障定位到具体线/位
5. **确定性 LCG**：自检可复现（同一种子同结果）
6. **Memcpy32 展开**：FSMC 16 位总线性能优化
