# OpenART mini 固件升级指南

> 硬件：OpenART mini V3.1（NXP i.MX RT1064）
> 当前固件：MicroPython v1.18 / OpenMV V4.3 / HAL v1.1.0（实测确认）
> 目标：升级到 OpenMV v4.5.6+（新 ML Module → YOLO 目标检测能力）
> 更新：2026-08-16（全网资料汇总）

---

## 一、为什么要升级

| 固件 | ML 能力 |
| --- | --- |
| **V4.3（当前）** | `tf` 模块仅分类（classify）；`nncu` 逐飞分类模型 |
| **v4.5.6+（目标）** | 新 ML Module（`nn` 模块），官方在 RT1062/RT1064 实测 **YOLO 2-3 FPS**（QVGA，工业低频取帧可用） |

## 二、固件从哪来（重要：IDE 通用升级不可用）

OpenMV IDE 弹"固件已过时"点确认后会报 **"不支持的主板架构"**——IDE 内置 boards 表只有
标准 OpenMV 主板（STM32 系列），**没有 OpenART mini（RT1064 定制板）**，无法用它升级。
固件必须来自**逐飞官方**（OpenART mini 是逐飞定制固件，基于 OpenMV 源码移植）：

| 渠道 | 方式 |
| --- | --- |
| **淘宝客服**（逐飞科技店） | 最直接：问"OpenART mini V3.1 最新固件 + 升级教程" |
| **逐飞官网** seekfree.cn/products | 资料下载区（部分需登录/注册） |
| **逐飞微信公众号** | 回复关键词（如"OpenART"）获取资料链接 |
| **智能视觉组交流群** | 群文件常有固件包与工具 |
| 恩智浦大赛平台 nxpic.org.cn | 历届培训资料（含固件/工具） |

索要时明确：**"基于 OpenMV v4.5.6+ 的 OpenART mini 固件（.axf/.bin/.dfu）+ 配套升级工具"**。

## 三、升级工具（两条路）

### 路线 A：NXP MCU Boot Utility（社区与 NXP 官方通用）

RT1064 的 ROM bootloader 支持 **USB HID 串行下载模式**，用 NXP 官方工具一键烧录：

- 官方工具：**mcu-boot-utility v3.4.0**（41MB，含 exe）
  https://github.com/nxp-mcuxpresso/mcu-boot-utility/releases/download/v3.4.0/mcu-boot-utility-3.4.0-with-exe.zip
- 社区版（更流行，智能车圈常用）：**NXP-MCUBootUtility**（KKKelvin7/NXP-MCUBootUtility，
  GitHub 搜索同名仓库；18 届 OpenART 固件烧录即用此工具）

**通用烧录步骤**（RT1064 系）：
1. 断开 USB，**按住 OpenART mini 的 BOOT/BOT 按键**不放
2. 插入 Type-C 线（继续按住约 1-2 秒后松开）→ 进入串行下载模式（USB HID）
3. 打开 MCU Boot Utility → 识别到设备（RT1064）→ 选择固件文件（.axf 或 .bin）
4. 点烧录（一键连接+擦除+写入）→ 完成后复位（按 RST）→ 正常启动
5. 验证：OpenMV IDE 连接 → 串行终端首行显示新固件版本（v4.5.x）

> 提示：若烧录 .bin 需注意起始地址（RT1064 应用区，通常 0x60000000 附近，
> 以逐飞教程/固件包说明为准；.axf 格式工具自动处理地址）。

### 路线 B：逐飞官方提供的升级工具/流程

逐飞各代 OpenART 常随固件附带烧录说明（可能是上述 MCU Boot Utility，
也可能是逐飞定制上位机）——**以逐飞客服/教程为准**，流程一般为：
`按住 BOOT 上电 → 打开官方工具 → 选固件 → 烧录 → 复位`。

## 四、自行编译固件（进阶，不推荐新手）

OpenMV 源码开源且支持 RT106x 移植；NXP 官方仓库 nxp-mcuxpresso/OpenART 含
`imxrt1064-seekfree-art-mini` BSP（社区反馈 BSP 尚不完整）：
- OpenMV 源码：https://github.com/openmv/openmv
- NXP OpenART 工程：https://github.com/nxp-mcuxpresso/OpenART
- 难度：需要搭建 ARM GCC 工具链 + 配置板级（sensor/引脚/内存）——除非有明确需求，优先走路线 A/B

## 五、升级后验证清单

1. IDE 连接（点取消跳过"固件过时"提示的习惯可保留）
2. 串行终端首行版本号 ≥ v4.5.6
3. 老脚本兼容性：sensor/图像 API 不变；`nncu` 模型若不再支持则改用 `nn` 模块加载
4. YOLO 测试：加载官方/逐飞 YOLO tflite 模型 → 实测帧率（预期 2-3 FPS）
5. cmm_cfg.csv：升级后引脚映射若有变化，需用新版必备文件（问逐飞要）

## 六、结论与建议

1. **第一步**：联系逐飞客服要 v4.5.6+ 固件 + 升级说明（免费，官方支持）
2. **工具**：收到固件包后若未附工具，用 **mcu-boot-utility v3.4.0**（本文档已给直链）
3. **当前 V4.3 不耽误开发**：nncu 分类 + Apriltag + 色块/矩形检测已可覆盖智能车视觉需求，
   YOLO 升级后可平滑切换
