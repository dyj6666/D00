# 手势数据采集操作指南（自己动手版）

> 脚本：`CAMERA/scripts/collect_gestures.py`
> 目标：采集 6 类手势，每类 60 张（约 15 秒/类），总耗时约 10 分钟

## 每类的操作循环（共 6 次）

### 第 1 步：改类别名
在 OpenMV IDE 打开 `collect_gestures.py`，找到开头配置区的这一行：

```python
CLASS = "fist"          # ← 每次运行前改成当前手势名
```

**第一次不用改**（默认 fist）。之后每轮改成下一个名字：
`fist` → `palm` → `one` → `two` → `ok` → `victory`

### 第 2 步：运行
点 IDE 绿色运行按钮（F5）

### 第 3 步：比手势
终端出现：
```
COLLECT [fist] 目标 60 张，请把手比好手势放镜头前（可缓慢微动）
```
把手比好手势放到镜头前（画面中偏下，手占画面 1/5~1/3），**保持不动或轻微晃动**约 15 秒。
终端会滚动：
```
[12/60] saved /sd/gesture/fist/012.jpg
[13/60] saved ...
```

### 第 4 步：确认完成
看到 `COLLECT DONE [fist] 60 张，换下一个手势改 CLASS 重跑` → 点红色停止按钮

### 第 5 步：下一类
改 `CLASS = "palm"` → 运行 → 比"五指张开"手势 → 等待 60 张 → 停止……

> 采集时画面里会显示：红框=手位置，绿框=实际裁剪保存的区域

## 采集技巧（决定模型质量）

1. **背景简单**：纯色墙/桌面，别太多杂物（模型只看手，背景越干净越好）
2. **手要大**：离镜头近一点，让手占画面明显面积
3. **轻微变化**：采集过程中手腕微转、远近微调、手指微动——让每张都不一样（增强泛化）
4. **光线稳定**：别对着强光/忽明忽暗
5. **漏采补采**：某类手滑了（中途手移出），直接重跑该类（会覆盖重采）

## 采集完成后（拷数据给训练）

1. 断开 IDE 连接（或拔插 Type-C），等 G: 盘出现
2. 把 **`G:\gesture`** 整个文件夹复制到电脑：
   `D:\GIT-SPACE\D00\CAMERA\train\dataset\`
   （最终结构：`dataset\fist\000.jpg ... 059.jpg`、`dataset\palm\...` 等 6 个子目录）
3. 告诉我"数据采完了"，我开始训练模型
