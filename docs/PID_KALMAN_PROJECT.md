# 《灵眸云台》—— 视觉伺服 × 姿态融合 全算法实验室
### PID 与卡尔曼滤波全家族实战项目设计方案（V1.0）

> 目标：基于现有硬件（STM32F407ZGT6 + OpenART mini 摄像头 + MPU6050 + 双轴舵机云台），
> 以"视觉目标追踪"为主线，系统性实现并实战验证 **PID 全部 12 种变式** 与
> **卡尔曼滤波全部 12 种变式**，产出教程级《全算法实战手册》与可复用算法库。

---

## 1. 项目定位与愿景

**一句话**：一台能"盯着目标转、抗干扰、预测目标"的智能双轴云台——它是
**视觉伺服（Visual Servoing）**、**姿态估计（State Estimation）**、**闭环控制（Control）**
三大经典领域的完整实验平台，每个算法家族都在真实硬件上跑出对比数据。

**为什么是云台**：
| 维度 | 云台的优势 |
|---|---|
| 控制 | 双轴（PAN/TILT）+ 舵机 = 经典双闭环控制对象（角度环+角速度环） |
| 感知 | MPU6050 测自身姿态 + 摄像头测目标偏差 = 双传感器融合（IMU×视觉） |
| 延迟 | 视觉链路 ~30-100ms 真实延迟 = 史密斯预估/卡尔曼预测的最佳战场 |
| 可视化 | LCD/LVGL 实时曲线 = 每个算法变式的对比数据直接可见 |
| 工程化 | 复用现有 OTA/ETH/CAN/LVGL/单测/文档流水线 |

## 3. 系统架构（三端 + 五层数据流）

```
┌─────────────── 数据流（1kHz 控制周期主环） ───────────────┐
│                                                           │
│  [感知层]  MPU6050 1000Hz ──► 姿态滤波（互补/KF/EKF/UKF）──► 角度/角速度 (θ, ω)   │
│           OpenART 30Hz   ──► 目标检测 ──► α-β/KF/IMM 目标状态 (x, v)           │
│                                                           │
│  [参考层]  目标像素偏差 ──► 坐标映射 ──► 期望云台角 θ_ref（含预测补偿）          │
│                                                           │
│  [控制层]  外环（位置）：视觉/角度 PID ──► 期望角速度 ω_ref                     │
│           内环（速度）：角速度 PID ──► PWM ──► 舵机 ──► 云台物理运动             │
│           （史密斯预估/前馈/抗饱和/积分分离/增益调度全挂载）                     │
│                                                           │
│  [观测层]  LCD 实时曲线：θ_ref/θ/误差/输出 + 算法 A/B 对比                      │
│           ETH 远程：状态上报/参数下发/实验数据采集                              │
│                                                           │
│  [录制层]  逻辑分析仪采样（已有 LA 模块）：PWM/中断时序验证                      │
└───────────────────────────────────────────────────────────┘
```

**关键设计决策**：
1. **双环串级为主架构**（视觉外环→云台角度环→舵机），滤波家族全挂在感知层，
   PID 家族全挂在控制层——两大算法家族互不干扰、可独立切换对比
2. **算法即插即用**：`control/pid.h`（12 变式统一接口）+ `control/kalman.h`（12 变式统一接口），
   运行时可切换（A/B 对比），参数经事件总线下发（触摸/ETH）
3. **每变式一个实验场景**：同一场景跑 2 种算法 → LCD 叠画曲线 → 数据落盘 → 自动生成对比报告

## 4. 算法全景图（12+12 变式 → 落点映射）

### 4.1 PID 家族（12 变式 → 云台控制落点）

| # | 变式 | 原理要点 | 本项目落点 | 实验场景 |
|---|---|---|---|---|
| 1 | 位置式 PID | u = Kp·e + Ki·∫e + Kd·ė | 云台角度环基础 | S1 阶跃整定 |
| 2 | 增量式 PID | Δu = Kp·Δe + Ki·e + Kd·ΔΔe | 舵机输出平滑（防抖） | S1 对比 |
| 3 | **串级 PID** | 外环位置→内环速度 | **云台主架构**（角度+角速度双环） | S2 正弦跟踪 |
| 4 | 前馈 PID | u += 目标速度/重力补偿前馈 | 视觉目标速度前馈 + TILT 重力补偿 | S2 跟踪 |
| 5 | 积分分离 | |e|>阈值 禁积分 | 目标丢失/大偏差瞬间 | S4 遮挡 |
| 6 | 抗饱和 | clamping + back-calculation | 舵机限幅（±90°）防积分饱和 | S1 大幅阶跃 |
| 7 | 微分先行 | D 作用于测量（非误差） | 视觉噪声放大抑制 | S2 噪声对比 |
| 8 | 增益调度 | 按目标距离/速度分档 Kp/Ki/Kd | 远目标粗调/近目标精调 | S3 机动 |
| 9 | 模糊 PID | 误差/误差率→模糊规则→ΔK | 无需精确模型的整定演示 | S1/S2 |
| 10 | **史密斯预估器** | 模型预测补偿延迟 e^(-τs) | **视觉 30-100ms 延迟补偿（核心亮点）** | S2 延迟对比 |
| 11 | bang-bang+PID | 大误差粗瞄/小误差精调 | 快速捕获目标 | S4 重捕获 |
| 12 | 自适应 PID | 极限环检测→在线调参 | 参数自整定演示 | S1 变参数 |

### 4.2 卡尔曼家族（12 变式 → 感知落点）

| # | 变式 | 原理要点 | 本项目落点 | 实验场景 |
|---|---|---|---|---|
| 1 | 互补滤波 | 高通过陀螺+低通过加速度 | 姿态基线（对比基准） | 姿态对比 |
| 2 | α-β 滤波 | KF 恒定速度模型特例 | 视觉目标位置/速度平滑 | S2 跟踪 |
| 3 | 标准 KF | 线性高斯递推 | 现有 kf2d 升级：云台角速度估计 | 姿态对比 |
| 4 | **EKF** | 一阶线性化 | 姿态非线性（欧拉角/四元数）估计 | 姿态对比 |
| 5 | **UKF** | sigma 点无迹变换 | 强非线性姿态（大角度机动） | 姿态对比 |
| 6 | 自适应 KF | 创新序列协方差匹配→Q/R 在线估计 | 噪声变化环境（振动台） | S5 扰动 |
| 7 | **IMM** | 多模型加权（静止/匀速/机动） | 目标运动模式切换跟踪 | S3 机动 |
| 8 | RTS 平滑 | 双向滤波（后向校正） | 离线数据回放对比 | 录制回放 |
| 9 | 信息滤波/平方根 | 数值稳定变式 | 大矩阵/低精度演示对比 | 数值对比 |
| 10 | KF+PID 结合 | 滤波输出作反馈（噪声统计化） | 全部控制环默认配置 | 全场景 |
| 11 | 视觉-IMU 融合 | 像素偏差×云台角度加权 | 目标世界坐标估计 | S3 机动 |
| 12 | **KF 预测补偿** | 状态预测填补视觉延迟 | **目标位置前向预测（核心亮点）** | S2 延迟对比 |

### 4.3 交叉亮点（项目"顶级"所在）
- **视觉延迟补偿组合拳**：史密斯预估（控制侧）+ KF 预测（感知侧）——同一 80ms 延迟两种解法同台对比
- **IMM×PID 联动**：目标机动模式（IMM 输出）→ 驱动 PID 增益调度
- **姿态基准竞赛**：互补 vs KF vs EKF vs UKF 同一 MPU6050 数据流，LCD 叠画四曲线
- **全链路演示**：手动摆动目标 → 云台自动咬住 → 遮挡 2s → 预测续行 → 重捕获

## 7. 实验设计（对比基准——保证"全部应用"可验证）

**5 大标准场景**（每场景跑全部相关变式，同一输入数据流）：
- **S1 阶跃**：0→30° 阶跃，指标：超调/调节时间/稳态误差（PID 整定对比）
- **S2 正弦跟踪**：目标 ±20° @0.2-1Hz 正弦，指标：跟踪 RMS 误差（PID 变式 + 延迟补偿对比）
- **S3 机动**：目标匀速→突然加速/反向，指标：最大瞬态误差/收敛时间（IMM vs 单模型 KF、增益调度）
- **S4 遮挡**：目标消失 2s，指标：重捕获时间、预测续行精度（积分分离/预测补偿）
- **S5 扰动**：手动拨动云台，指标：恢复时间、超调（抗饱和/自适应）

**数据采集**：ETH 上报 1kHz 控制数据 → 上位机落盘 → 自动生成对比表（RMS/峰值/CPU/内存/帧率）→ 入《实战手册》附录。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 舵机带宽低（~50Hz）限制控制周期 | 控制周期 1kHz 运算、输出限幅平滑；文档注明舵机机械极限 |
| 摄像头延迟大导致振荡 | 史密斯预估 + KF 预测双补偿（项目核心亮点） |
| MPU6050 振动噪声大 | 减震安装 + 滤波家族对比（正是实验内容） |
| 视觉 30Hz 与 IMU 1kHz 异步 | 时间戳对齐 + 零阶保持 + KF 多速率融合 |
| 云台机械回差（舵机死区） | 死区补偿（PID 输出前死区消除）——第 13 个实战技巧 |
| 双轴耦合（PAN 转动影响 TILT 重力向量） | 前馈解耦 + 实验记录 |
